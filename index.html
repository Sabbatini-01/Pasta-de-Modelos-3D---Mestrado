Como controlar

Visualização normal

Botão esquerdo + arrastar: gira o modelo
Botão direito + arrastar: desloca a câmera (pan)
Rolar o scroll (ou pinçar na tela): zoom

Modo de edição

Clique numa peça: seleciona
Seta vermelha do gizmo: eixo X
Seta verde do gizmo: eixo Y
Seta azul do gizmo: eixo Z
Ctrl+Z (ou ⌘+Z): desfaz o último movimento

Controle de luz, sombra e visualização

Modo de edição —

Clique numa peça do modelo para selecioná-la e arraste as setas/anéis para movê-la, girá-la ou escaná-la. Clique em uma área vazia para desselecionar. Use Ctrl+Z (ou o botão Desfazer) para reverter o último movimento. Quando terminar, clique em "Salvar como novo .glb" para baixar um arquivo novo com as peças nas posições atuais — o arquivo original não é alterado. Use "Gerar .stl para impressão 3D" para baixar um arquivo pronto para fatiadores de impressão 3D, já na escala (em milímetros) que você definir.
